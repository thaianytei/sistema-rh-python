# sistema-rh-python
📝 Sistema de Gestão de RH (RH System)
Este é um sistema de gerenciamento de recursos humanos desenvolvido para facilitar o controle de funcionários, permitindo o cadastro, visualização de status (Ativos/Inativos) e armazenamento de documentos.

🚀 Funcionalidades
Dashboard Interativo: Visualização rápida do total de funcionários, quantos estão ativos e quantos estão inativos.

Gestão de Funcionários: Cadastro completo com Nome, CPF, Cargo, Salário e Status.

Filtros Inteligentes: Navegação lateral que permite filtrar a lista de funcionários por status em tempo real.

Upload de Documentos: Sistema integrado para anexar e baixar documentos (PDFs/Imagens) relacionados ao funcionário.

Sistema de Login: Acesso restrito via autenticação simples para garantir a segurança dos dados.

Banco de Dados: Utilização de SQLite para armazenamento persistente e leve.

🛠️ Tecnologias Utilizadas
Linguagem: Python

Framework Web: Flask

Banco de Dados: SQLite3

Front-end: HTML5, CSS3 (Design responsivo e moderno)

Ícones: Font Awesome
